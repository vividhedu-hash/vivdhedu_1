# crawl4ai is a JS-capable crawler used only by scrapers/crawl4ai_scraper.py,
# which imports it lazily and degrades gracefully when it is absent.
#
# It cannot be a hard dependency: every crawl4ai release requires
# pydantic>=2.10, while this project pins pydantic==2.8.2 (a FastAPI 0.115

# outright on every clean machine, which is why no CI job could ever install
# the backend and no test job existed.
#
# To enable the crawl4ai scraper, upgrade pydantic first, then:
#   pip install crawl4ai==0.4.246 && crawl4ai-setup
crawl4ai==0.4.246 ; python_version >= "0" and extra == "crawl"
